- Activity Log
  - [List events](https://developer.runn.io/reference/get_activity-log.md): Get a list of events that have occurred. Expand the RESPONSES (200) panel below to see supported events. Test accounts are not supported. More events will be added in the future.

  - [Create or overwrite an actual](https://developer.runn.io/reference/post_actuals.md): Actuals are matched on date, project, person, role, and workstream. Minutes values represent the total time for the day and overwrite any previous actual with the same `date`, `projectId`,…
  - [Create or overwrite actuals in bulk](https://developer.runn.io/reference/post_actuals-bulk.md): Create or overwrite up to 100 'actuals' in a single API call. Each actual is matched on date, project, person, role, and workstream, and its minutes overwrite any previous actual for that…
  - [Delete a specific actual](https://developer.runn.io/reference/delete_actuals-actualid.md): Deletes the actual record identified by the provided unique identifier `actualId`. This operation is irreversible and removes the actual record from the system.
  - [List actuals](https://developer.runn.io/reference/get_actuals.md)
  - [Create or add to an existing actual](https://developer.runn.io/reference/post_actuals-time-entry.md): Adds minutes to an existing actual.
